💻 研究员远程只读挂载查询链接串 (Python / R DuckDB Query Snippet)
协议: HTTPFS / GCS Direct Read 
import duckdb

# 1. 建立内存会话并加载远程网络文件系统扩展
con = duckdb.connect()
con.execute("INSTALL httpfs; LOAD httpfs;")

# 2. 远程只读直连 GCP 冷数据 Parquet 底座 (零下载、流式谓词下推)
df = con.execute("""
    SELECT date, symbol, open, high, low, close, volume, vwap
    FROM read_parquet('https://storage.googleapis.com/quant-fmp-datalake/prices/daily/*.parquet')
    WHERE symbol IN ('NVDA', 'AAPL', 'MSFT', 'SPY') AND date >= '2020-01-01'
    ORDER BY date ASC
""").df()

print(f"成功挂载查询完成，获取样本行数: {len(df)}")

FMP 双 Key 额度池渐进式入库计划 (Ingestion RoadMap · 500 次/天)

额度分配准则：每日最新数据全量覆盖 (100%) + 剩余额度全额回填历史 (Residual Waterfall)

① 当日全美最新数据采集 (Priority 1)：使用日度批量轻量接口仅需 1~5 次请求即可一次性拉取全美数千只股票当天最新日K，并结合财报日历靶向拉取今日新财报三大表；
② 实时新闻舆情同步 (Priority 2)：调用新闻接口同步全市场重点标的最新重磅新闻与公告，为动态动量干预 (News Calibration) 提供情绪评分与熔断信号；
③ 剩余额度回填全部历史 (Priority 3)：双 Key 额度池扣除最新数据与新闻开销后，每日结余的 460+ 次额度（占比 >90%）全额自动投入历史数据全量回填。按双重排序（主要股票优先 + 近端时序优先），由状态机持久化断点续传直至达成全美所有股票全部历史数据 100% 入库的终极目标。
