二、 真实资金安全：五道防御工事 (5-Layer Safety Guardrails)

操作真实账户资金必须杜绝任何系统异常、网络震荡或模型过拟合导致的本金损失
100% 自动化风控看门狗
LAYER 01 · 凭证与通信隔离
凭证物理隔离与最小权限

宿主机、云盘与前端代码中绝不保存任何 API Key 或交易私钥。实盘凭证由 GCP Secret Manager 独立加密托管，仅通过 Cloud NAT 固定白名单出口 IP 访问券商通道。

Zero Local Secrets
LAYER 02 · 事前风控硬指标
事前风控硬阈值拦截闸门

报单前强制硬性检查：单票持仓上限 ≤ 10.0%（严防暴雷）；日内浮亏 -2.5% 触发软熔断（禁止新开仓）；日内浮亏 -4.0% 触发硬熔断（清退日内所有头寸并锁定 24h）。

Hard Stop Redline
LAYER 03 · 订单执行保护
订单执行防滑点与流动性保护

绝对禁止纯市价单；标的过去 30 日日均成交额必须满足 ADV ≥ $20,000,000；挂单未成交 60 秒自动撤单（TTL=60s）；回避美股开盘前 15 分钟与收盘前 10 分钟剧烈波动。

Limit Protection
LAYER 04 · 事中实时对账
事中实时对账与断网心跳检测

交易引擎每隔 15 秒拉取券商真实持仓，与目标头寸双向对账校验；进程与健康检查服务维持 10 秒一次心跳包。若网络中断超 30 秒，券商预挂安全保护单自动生效并强制报警挂起。

Heartbeat & Reconciliation
LAYER 05 · 人工全局制动
全局物理紧急制动开关 (Kill-Switch)

无论系统处于何种运行状态，均可通过专属紧急指令触发 KILL_SWITCH：急刹车模式立即撤销全市场挂单；紧急清算模式以算法在 10 分钟内平仓回退至 100% 现金避险。

Global Kill Switch

• 通道定位: 原生云端 REST/WebSocket 算法接口，适合轻量级沙盒与免佣碎股交易。
• 核心优势: 官方免费 Paper Sandbox、支持 Fractional Shares、毫秒级 Webhook 成交回报。
• 状态: 已通过本地连通性与看门狗审计，专职承载 30 日零成本沙盘验证。

Interactive Brokers (盈透证券) 机构级生产通道预留

• 通道定位: 全球机构级多资产清算通道 (TWS API / Client Portal Web API)。
• 核心优势: 极低融资利率、全球交易所深度流动性接入、极其严苛的合规清算牌照。
• 状态: 生产架构设计就绪，支持在实盘资本扩容后无缝切换路由。

五、 实盘见证准则与数据脱敏标准 (Live Witness Protocols)

严格遵循金融监管与滑点保护防线 · 严禁直接公开真实交易执行流水
合规与隐私保护
三大禁止公开流水的核心风险 合规红线

1. 安全与隐私风险：绝对金额与资金流向暴露极易招致网络侦查与反向头寸推导。
2. 滑点与容量衰减：公开暴露个股与时间戳极易引发跟风抢跑（Front-Running），剧烈推高市场冲击成本。
3. 监管合规风险：未经投资顾问牌照（RIA）无延迟公开下单指令，极易被司法定性为非法跟单指导。

实盘见证模块三大开放维度 学术与统计见证

1. 归一化净值曲线 (Normalized NAV)：对外净值以基期 1.0000 进行标准化，严禁暴露本金数字，对比 SPY 计算 Beta 与 Alpha。
2. 核心风险指标卡片：公开展示真实市场摩擦下的夏普比率、索提诺比率、最大回撤与胜率。
3. T+1 延迟脱敏持仓统计：仅在交易日收盘后导出 GICS 一级行业权重与多空净敞口。
